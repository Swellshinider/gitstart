# Support

## Questions and setup help

Search existing issues first, then open a
[GitHub Issue](https://github.com/Swellshinider/gitstart/issues) with:

- operating system and Node.js version;
- the agent you use (Claude Code, Codex, Cursor, VS Code, or Gemini CLI) and its version;
- how you installed GitStart (plugin or `gitstart-cli`) and its version;
- the command or prompt where the problem appears, with secrets and private data removed.

Start with the project documentation:

- [`README.md`](README.md) - installation and usage
- [`docs/development.md`](docs/development.md) - running from a checkout and validation
- [`docs/architecture.md`](docs/architecture.md) - how the skills and installer fit together

## Bugs and feature requests

Use the repository's bug-report or feature-request template. Include a minimal
reproduction, expected behavior, actual behavior, and relevant context.

## Security issues

Do not use public Issues for vulnerabilities. Follow [`SECURITY.md`](SECURITY.md).
